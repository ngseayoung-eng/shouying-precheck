# shouying-precheck · 医药首营资料 AI 预审技能

> An AI pre-review skill for pharmaceutical supplier/product qualification dossiers (首营资料), built on China GSP requirements. Chinese pharma supply-chain focused; README in Chinese.
>
> 把供应商微信发来的首营资料丢给 AI 助手，它按 GSP 要求逐项清点、跨文件核对，输出一份**可以直接转发回供应商的补料清单**——目标是：供应商一次交齐，质管一次过，不用来回补料。

## 它解决什么问题

首营（首次与供应商/品种建立经营关系）资料审核，是每家药店连锁、批发企业、诊所供应链都绕不开的活：供应商发来的证照图片质量参差，缺什么、哪张过期、规格对不对，靠人眼一项项对，漏一项质管打回一次，来回折腾两三周。

这个技能装进你的 AI 助手（Claude Code / 其他支持技能机制的助手）后，采购或商务把资料包一丢，它干完预审员的活：**清点 → 确认范围 → 禁售闸 → 逐项核验 → 跨文件核对 → 出报告 + 补料清单**。供应商一次交齐的命中率，就是省下来的一轮轮微信拉锯。

## 这个技能的工程纪律（为什么它不是"又一个提示词"）

在真实连锁药店环境里三个 AI 助手平台实测、迭代十余个版本、经质量管理部门多轮口径校准后沉淀下来的规矩，每条背后都是一次实测翻车：

- **交互门**：先清点发确认消息（只报类别份数、不带任何结论词），得到使用人答复前禁止开审——防止 AI 自作主张"先审了再说"
- **盲区 ≠ 缺失**：OCR 读不出的文件不许判"缺失"、不许列补件——读不出 ≠ 没有
- **数字多源校验**：证号/条码/效期至少两源读取（PDF文本层 → 视觉 → 放大重读），EAN-13 条码自算校验位（纯算术可自验），两源不一致禁止择一写入
- **69 码三方核对**：采购拟建商品的码 ↔ 供应商商品表 ↔ 包装样稿实印码，三方对不上就转内部确认，不硬判
- **跨文件核对判断不进对外清单**：规格不一致、权属存疑这类判断只提给质管，不能变成对供应商的补料要求——对外件必须可自证、可申诉
- **模板锁定 + 8 断言自检门**：报告只能由模板填空生成，交付前逐条自检（计数成立、无占位符残留、指纹本包实算……）
- **运行指纹**：每份报告带资料包 sha256 指纹与 OCR 覆盖率，可追溯

## 适合谁

- 连锁药店 / 医药批发企业的采购、商务、内勤
- 诊所供应链、慢病平台、电商代运营的资质审核岗
- 给药企做 GSP 咨询、想加一条 AI 预审服务线的顾问

**重要边界**：预审 ≠ 质量管理部门的法定审核。本技能只做提交质管前的自查；规则为公开法规版（GSP、《药品网络销售监督管理办法》、网售禁售清单、官方查询入口），**不构成合规意见**，执行以法规原文与贵司制度为准。

## 安装

**Claude Code（推荐）**：把 `shouying-precheck/` 整个文件夹复制到 `~/.claude/skills/`（Windows：`C:\Users\你的用户名\.claude\skills\`），重启会话即生效。对话里说"首营预审"并丢资料包即可触发。

**其他 AI 助手**：把 `shouying-precheck/SKILL.md` 全文发给助手作为工作指令，同时把同目录 `template.html` 一并发给它（出报告时用）。

详细用法见 [docs/安装与使用.md](docs/安装与使用.md)。

## 使用（真实流程五步）

1. **丢资料**：供应商发来的首营资料（zip/图片/文件）直接丢给它
2. **答确认**：它先自己清点，跟你确认范围 / 拟建商品和 69 码 / 缺口——答完出报告
3. **发供应商**：复制报告里「补料清单」那块（带一键复制按钮），直接发回供应商——只发这一块
4. **循环**：对方补的文件再丢给它重跑，直到「资料齐全，建议提交质管复核」
5. **交质量**：预审通过交质管正式审核；供应商对判定有异议 → 转质量部门裁决

## 换成你公司的制度版规则

附录规则是**可整体替换的**：把你公司的首营管理制度蒸馏成同结构的规则文件（规则 ID 稳定、分节不变），技能即刻按贵司口径执行。怎么做见 [docs/规则定制指南.md](docs/规则定制指南.md)。**需要作者协助做制度版定制与落地，欢迎开 Issue 联系。**

**作者：吴思洋**（医药供应链 + AI 落地）。曾任广交物流（全国跨省异地多仓、医药电商供应链一体化经营企业）高管、现供应链顾问；运营 O2O 即时零售连锁，涉足跨境医药。
