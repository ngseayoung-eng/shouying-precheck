# 首营预审技能 · 安装与使用说明

## 这是什么

一个装在你 AI 助手里的「首营资料预审员」。供应商微信发来的资料图，丢给它，它按 GSP 要求和首营规则逐项过一遍，告诉你：缺什么、哪里不合规、哪些要重拍——并直接生成一段**可以原样复制发给供应商的补料清单**。目标：供应商一次交齐，质管一次过，不用来回补料。

**注意：预审只是提交质管前的自查，最终以质量管理部门审核为准。**

## 怎么装（一次性）

**Claude Code**：把 `shouying-precheck/` 文件夹（内含 SKILL.md 与 template.html 两个文件）复制到：

- 全局安装：`~/.claude/skills/shouying-precheck/`（Windows 完整路径：`C:\Users\你的用户名\.claude\skills\shouying-precheck\`）
- 单项目安装：项目目录下 `.claude/skills/shouying-precheck/`

复制完重启会话，说一句"首营预审"能触发即装好。

**其他支持自定义指令/技能的 AI 助手**：把 `SKILL.md` 全文发给助手作为工作指令；`template.html` 放到助手可读的位置，并在对话里告诉它路径（出报告时它要读模板填空）。助手不能读写文件的话，报告的"纯文本兜底"模式仍可用，但体验打折——推荐用有文件能力的助手。

**更新版本**：覆盖安装后重启会话即可。规则版本号在 SKILL.md 附录头部，可对照更新说明。

## 怎么用（真实流程五步）

1. **丢资料**：供应商发来的首营资料（zip/图片/文件）直接丢给它
2. **答确认**：它先自己清点，跟你确认范围 / 要建的商品和69码 / 有没有还没发来的——答完出报告
3. **发供应商**：复制报告里「补料清单」那块（带一键复制按钮），**直接发回供应商**让他们补——只发这一块，报告其他部分别外发
4. **循环**：对方补的文件再丢给它重跑，直到报告显示「资料齐全，建议提交质管复核」
5. **交质量**：预审通过后交质量部门正式审核；**供应商对哪条判定有异议 → 把报告对应那节转给质量部门裁决**

## 它的规矩（知道就行）

- 你没答复确认消息前，它不出任何结果——故意的，防它自作主张
- 图片模糊它不硬猜，标 ❓ 让你找供应商重拍——预审要可信
- 证照 **3 个月内到期**标 ⚠️ 临期，顺手让供应商换新，省得质管回头又催
- 品种资料先查**网售禁售清单**（疫苗/含麻复方/普瑞巴林这类），命中直接红灯，别再推进
- 一次只审一家供应商，换家开新会话
- 证件图片只用于本次预审，不保存不外传
- 报告末尾有一行 `[预审登记]`，是统计用的，不用管它、也别删

## 发现它说错了怎么办

规则条目都有 ID（如 VG3、CHK-8、PROC-8）。截图 + 规则 ID，到仓库开 Issue 说明场景——规则文件会修订发版，覆盖安装即修正。

## 换成你公司的制度版

本仓库附带的是公开法规版规则。你公司有自己的首营管理制度（该收什么、豁免什么、口径怎样），把制度蒸馏成同结构规则文件整体替换附录即可，做法见 [规则定制指南.md](规则定制指南.md)。
